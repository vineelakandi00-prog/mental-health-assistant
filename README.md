# Mental Health Assistant 🧠💬

A simple web app that helps analyze user text and suggest mental‑health strategies.  
Built with **Flask (Python)** for the backend and **HTML/CSS/JavaScript** for the frontend.

---

## 🚀 Features
- Analyze user input for emotional tone (happy, sad, neutral).
- Suggest simple coping strategies.
- Frontend built with HTML/CSS/JS.
- Backend powered by Flask.
